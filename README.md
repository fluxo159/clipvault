# ClipVault

**Менеджер буфера обмена для macOS на Electron.** История текста, ссылок, цветов и изображений в окне из строки меню.

## Возможности

- Поиск и фильтры: всё, текст, фото и ссылки.
- Закрепление нужных элементов и ограничение размера истории.
- Повторное копирование оригинального изображения.
- Светлая, тёмная и системная темы; горячая клавиша `⌘⇧V`.
- Необязательный настольный виджет и экспорт истории.

## Приватность

История и настройки хранятся локально в пользовательском каталоге приложения. Сервер, аккаунт и аналитические трекеры не используются. Домен скопированной ссылки не отправляется внешнему сервису ради иконки. История может содержать пароли и другие чувствительные данные: это локальное хранилище, не зашифрованный менеджер секретов.

В репозитории находятся исходники и синтетические тесты; личная история, настройки и установленное приложение не загружаются.

## Запуск и сборка

Нужны macOS и Node.js 24+.

```sh
npm ci
npm test
npm start
# Собрать DMG для arm64 и x64:
npm run build
```

`npm run preview` создаёт локальные снимки интерфейса с тестовыми данными. Сборки находятся в `dist/`; сертификаты подписи разработчик настраивает самостоятельно.

## Устройство

| Файл | Назначение |
|---|---|
| `main.js` | Окна, локальное хранилище и проверяемые IPC-команды |
| `preload.cjs` | Ограниченный мост между интерфейсом и Electron |
| `src/clipboard-watcher.js` | Чтение изменений буфера |
| `src/renderer.js`, `src/widget.js` | Основное окно и виджет |
| `src/security.js` | Проверка отправителя, путей изображений и настроек |

[Проверка безопасности и ограничения](docs/SECURITY_REVIEW.md). Изменение исходников не обновляет уже установленную копию автоматически.
