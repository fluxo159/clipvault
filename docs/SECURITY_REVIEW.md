# Проверка перед публикацией

Дата: 17 ноября 2026. Это проверка исходников и состава публикации, не сторонний пентест и не гарантия отсутствия всех уязвимостей.

## Общие проверки

- Gitleaks 8.30.1 с проверкой SHA-256 сканера: подготовленные файлы без находок секретов. Перед отправкой также сканируется вся новая Git-история.
- Проверены имена файлов и личные идентификаторы; рабочие .env, базы, cookies, журналы, локальные карточки и готовые старые приложения исключены.
- Git-автор использует GitHub noreply, а не личную почту.
- CI имеет только `contents: read`; Actions закреплены полными SHA, секреты сервера не используются.

## ClipVault

- Старый Electron и инструменты сборки обновлены; npm audit по полному lock-файлу: известных уязвимостей не найдено.
- IPC допускает только ожидаемые локальные главные окна приложения; чужие окна и iframe отклоняются.
- Чтение/удаление PNG ограничено сохранёнными изображениями истории; внешние пути и файловые симлинки отклоняются.
- Заблокированы новые окна, навигация, webview и запросы браузерных разрешений; sandbox и contextIsolation включены.
- Настройки проверяются по допустимым полям и диапазонам; экспорт CSV нейтрализует формулы.
- Убраны сетевые favicon-запросы для скопированных доменов; CSP запрещает сетевые соединения интерфейса.
- 7 тестов пройдены, включая проверки границ IPC, файлов и сохранности истории.

Override minimatch применяется только к двум зависимостям сборщика, использующим совместимый именованный API; он закрывает advisory GHSA-g3hv-75wg-m249. Сборщик и Electron закреплены lock-файлом.

История хранится локально открытым текстом, а не как зашифрованное хранилище паролей. Пользователь с доступом к профилю macOS может читать её. Установленная ранее копия приложения в этой задаче не заменялась; исправления относятся к исходникам. Подписанный/notarized релиз и полный пользовательский прогон отдельно не выполнялись.

## Ограничение локальной сборки

Дополнительные попытки сборки macOS и GUI-preview остановлены после длительного ожидания загрузки бинарного Electron. Результат сборки и GUI-прогон не подтверждены. Исходники прошли unit-тесты и CI; это не проверка готового приложения. Для установленной старой копии исправления ещё не применены.
